# GeoTestLab PRD Pack

This pack formalises GeoTestLab as a product after the initial application was already built.

## Documents

1. `01_GeoTestLab_Core_Product_Requirements_Document.md`  
   Canonical product vision, scope, users, lifecycle, current baseline, functional requirements, non-functional requirements, roadmap and definition of done.

2. `02_Power_Analysis_and_Test_Sizing_Specification.md`  
   Detailed requirements for the platform-agnostic power calculator, market sizing, spend and delivery feasibility, effectiveness evidence and recommendation logic.

3. `03_PRD_Traceability_and_Delivery_Roadmap.md`  
   Reconciliation of the current repository, the older hardening PRD and the new product plan, with a requirement matrix and implementation sequence.

## Recommended repository location

```text
docs/product/
```

The existing maintainability and UX hardening PRD should remain as a companion engineering programme, not the canonical definition of the product.
